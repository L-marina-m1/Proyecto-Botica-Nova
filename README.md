# Proyecto Botica Nova Salud

## Descripción
Desarrollo de una aplicación web para la gestión de una botica, que permitirá administrar productos farmacéuticos y facilitar su consulta.

## Objetivo
Desarrollar un sistema web aplicando tecnologías frontend y backend, utilizando una API REST para la comunicación entre ambos componentes.

## Tecnologías
- Git y GitHub
- Backend: API REST
- Frontend: HTML, CSS y JavaScript...
- Base de datos: por definir
